# AI Personal Finance System - Frontend

Frontend for the AI Personal Finance System.

## Planned Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router

## Responsibilities

- User Authentication
- Dashboard
- Transactions
- Budgets
- AI Insights
- Profile Management

The frontend communicates with the FastAPI backend using REST APIs.
Team members can decided best suitable means to build frontend..
